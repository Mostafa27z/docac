LMS V1 API Documentation

Interactive Mobile-First API specification. All authenticated endpoints require a Bearer Token in the Authorization header.

1. Authentication

POST /api/v1/auth/register
Registers a new student profile on the LMS platform.

Request Payload

{
  "name": "Mohamed",
  "email": "student@lms.com",
  "phone": "+201012345678",
  "password": "password123",
  "password_confirmation": "password123"
}

Response (201 Created)

{
  "success": true,
  "message": "Registration successful.",
  "token": "1|sanctum_token_plain_text",
  "data": {
    "id": 1,
    "name": "Mohamed",
    "email": "student@lms.com",
    "role": "student",
    "status": "active"
  }
}
POST /api/v1/auth/login
Authenticates user and issues Sanctum access token. Validates unique device registration for students.

Request Payload

{
  "email": "student@lms.com",
  "password": "password123",
  "device_uuid": "device_a_123"
}

Response (200 OK)

{
  "success": true,
  "message": "Login successful.",
  "token": "2|sanctum_token_plain_text",
  "data": {
    "id": 1,
    "name": "Mohamed",
    "email": "student@lms.com",
    "role": "student",
    "status": "active",
    "active_device_id": "device_a_123"
  }
}

2. Courses

GET /api/v1/courses
Fetch catalog listing of all published courses. Supports search and filters.

Query Parameters

?search=cardiology  # Searches titles and descriptions
?type=recorded      # Filters by: recorded, live, mixed

Response (200 OK)

{
  "data": [
    {
      "id": 1,
      "title": "Electrocardiogram (ECG) Interpretation",
      "slug": "electrocardiogram-ecg-interpretation",
      "description": "Learn how to read and interpret ECGs like a professional physician.",
      "thumbnail": "courses/thumbnails/course_1.jpg",
      "type": "recorded",
      "status": "published",
      "published_at": "2026-08-11T16:03:54Z"
    }
  ],
  "success": true,
  "message": "Courses retrieved successfully."
}
GET /api/v1/courses/{course}
Retrieve a specific course details along with its lessons and sections list.

Response (200 OK)

{
  "success": true,
  "message": "Course details retrieved successfully.",
  "data": {
    "id": 1,
    "title": "Electrocardiogram (ECG) Interpretation",
    "slug": "electrocardiogram-ecg-interpretation",
    "description": "Learn how to read and interpret ECGs like a professional physician.",
    "thumbnail": "courses/thumbnails/course_1.jpg",
    "type": "recorded",
    "status": "published",
    "published_at": "2026-08-11T16:03:54Z",
    "sections": [
      {
        "id": 1,
        "title": "Section 1: ECG Introduction",
        "sort_order": 1,
        "lessons": [
          {
            "id": 1,
            "title": "Lesson 1: Introduction to Cardiac Cycles",
            "type": "video",
            "video_duration_seconds": 600,
            "sort_order": 1,
            "is_preview": true
          }
        ]
      }
    ]
  }
}
POST /api/v1/courses/{course}/activation-code
Generates a unique activation code for the course. (Only accessible by Admin and the Course Instructor).

Response (201 Created)

{
  "success": true,
  "message": "Activation code generated successfully.",
  "data": {
    "code": "ELEC-ABCD-EFGH",
    "course_id": 1,
    "is_used": false
  }
}
POST /api/v1/courses/activate-with-code
Activates and subscribes a student to a course using a valid activation code.

Request Payload

{
  "code": "ELEC-ABCD-EFGH"
}

Response (200 OK)

{
  "success": true,
  "message": "Course activated successfully. You are now enrolled.",
  "data": {
    "course_id": 1,
    "course_title": "Electrocardiogram (ECG) Interpretation"
  }
}

3. Lessons & Progress

GET /api/v1/lessons/{lesson}
Fetch lesson details. Videos return a signed URL from Bunny CDN dynamically if the student is enrolled.

Response (200 OK)

{
  "data": {
    "id": 1,
    "title": "Lesson 1: Introduction to Cardiac Cycles",
    "description": "Basics of cardiac contraction and electrical impulse pathways.",
    "type": "video",
    "video_duration_seconds": 600,
    "sort_order": 1,
    "is_preview": true,
    "video_url": "https://cdn.test.com/courses/videos/lecture1.mp4?token=abc123xyz&expires=1786523600",
    "progress": {
      "watched_seconds": 50,
      "percentage": 8.33,
      "last_position_seconds": 50,
      "completed_at": null
    }
  },
  "success": true,
  "message": "Lesson details retrieved successfully."
}
POST /api/v1/lessons/{lesson}/progress
Track and save video watching progress percentage. Updates overall course completion percentage automatically.

Request Payload

{
  "watched_seconds": 550,
  "last_position_seconds": 550
}

Response (200 OK)

{
  "success": true,
  "message": "Progress tracked successfully.",
  "data": {
    "watched_seconds": 550,
    "percentage": "91.67",
    "last_position_seconds": 550,
    "completed_at": "2026-08-11T16:15:00Z"
  }
}

4. Quizzes & MCQs

GET /api/v1/quizzes/{quiz}
Fetch quiz questions. Option outputs hide key answer data from payload for exam security.

Response (200 OK)

{
  "success": true,
  "message": "Quiz retrieved successfully.",
  "data": {
    "id": 1,
    "title": "ECG Reading Basics MCQ Quiz",
    "questions": [
      {
        "id": 1,
        "question_text": "What does the P-wave represent on an ECG?",
        "options": [
          { "id": 1, "option_text": "Atrial depolarization" },
          { "id": 2, "option_text": "Ventricular depolarization" }
        ]
      }
    ]
  }
}
POST /api/v1/quiz-attempts/{attempt}/submit
Evaluate attempt responses. Marks lesson complete if passed.

Request Payload

{
  "answers": [
    {
      "question_id": 1,
      "selected_option_id": 1
    }
  ]
}

Response (200 OK)

{
  "success": true,
  "message": "Quiz attempt submitted successfully.",
  "data": {
    "attempt_id": 5,
    "score": 100.00,
    "passed": true,
    "total_questions": 1,
    "correct_answers": 1
  }
}

5. Live & Chat

POST /api/v1/live-sessions/{session}/join
Initiates attendance tracker session and outputs integration links (e.g. Zoom).

Response (200 OK)

{
  "success": true,
  "message": "Live session joined successfully.",
  "data": {
    "attendance_id": 2,
    "meeting_url": "https://zoom.us/j/9876543210",
    "meeting_id": "987 654 3210"
  }
}
